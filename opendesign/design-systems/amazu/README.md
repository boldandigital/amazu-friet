# Amazú Friet — Design System

The house identity for Amazú Friet, the sweet-potato friet house in Belém,
Pará. Plum canvas, gold foreground, Bodoni Moda over Jost.

## What is in here

```
DESIGN.md                    the canonical brand and design brief
SKILL.md                     the agent-facing brand rules
metadata.json                Open Design registration metadata
brand/voice-and-tone.md      how the house speaks
brand/style-notes.md         how the house looks
tokens/colors_and_type.css   the CSS custom properties
tokens/tokens.default.json   the machine-readable token set
assets/logos/                the lockup, the seal, the cart icon
assets/imagery/              product photography
assets/icons/                interface icons
fonts/                       Bodoni Moda and Jost webfonts
```

## The one-line version

Belgian technique, Portuguese soul. Everything is plum and gold, everything is
set in a Didone serif over a geometric sans, and nothing shouts.

## Where the system lives

- **Open Design brand:** `amaz-friet-design-system-f715c9` (status `ready`),
  with the generated kit in `system/` (kit.html, tokens, theme, artefacts).
- **Site:** `../web/` — Next.js 15 App Router, static export.
- **Open Design design:** `../designs/amazu/` — the self-contained HTML
  artefact, imported into Open Design as *Amazú Friet — Site*.

## Rules that never bend

1. Plum canvas, gold foreground, one appearance. No light mode.
2. No em-dashes and no exclamation marks in body copy.
3. No invented health, sustainability or sourcing claims.
4. Gold is flat. No gradients, no glow, no glitter.
5. One primary CTA per view.
